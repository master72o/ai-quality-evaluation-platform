# Figures Directory

This directory contains executive visual artifacts generated by the Enterprise AI Quality Platform:
- `platform_health_overview.png`: Bar chart breaking down the Quality Health Score (%) for all 7 evaluation pillars with the production gate threshold line (85%).
- `cross_pillar_quality_matrix.png`: Grouped bar chart comparing Total Evaluation Cases vs Passed Test Cases across all pillars.
- `executive_quality_dashboard.png`: Executive summary card displaying overall AI System Health Score and deployment approval status.
